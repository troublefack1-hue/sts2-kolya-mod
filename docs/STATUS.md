- Мутации с 4-го акта: 1/2/3 по актам 4–6/7–9/10, боссы по одной, 9 видов — Mutations.cs, Poisoner.cs (яд 2..8)
- Связка: половина потери ОЗ призывателя уходит приспешникам — Bond.cs
- Трофей за мутированную элиту: зачарование карты на выбор — EliteMutationReward.cs
- Все персонажи, вся летопись, золото ×1,5 — AllCharacters.cs, AllEpochs.cs, MoreGold.cs
- Вечный блок; Баррикада и Размытие убраны; Крепкий зажим = 5 блока за ход — KeepBlock.cs, SturdyClampRework.cs
- Бесконечное улучшение; 5-е улучшение даёт новое зачарование — MultiUpgrade.cs, FifthUpgradeEnchant.cs
- Повторы за лишние уровни для 102 карт без числового улучшения — ExtraPlays.cs
- Несколько зачарований на карте (составное зачарование, сохранение, сеть) — MultiEnchant.cs, NetSafety.cs
- Магазин: безлимитное удаление, «Обновить» (только одиночная) — UnlimitedRemoval.cs, ShopReroll.cs
- Слияние у костра с иконкой — Fuse.cs, option_fuse.png
