# Мод Kolya Mod для Slay the Spire 2 (версия игры 0.107.1), версия мода 0.2.0

1. В Steam: правый клик по Slay the Spire 2 -> Управление -> Просмотреть локальные файлы.
2. Распакуйте этот архив в открывшуюся папку (рядом с SlayTheSpire2.exe должна появиться папка mods).
3. Запустите игру из Steam. В главном меню откройте «Моды» и согласитесь включить моды,
   затем перезапустите игру.

С модами игра ведёт отдельный профиль: обычные сохранения не затрагиваются.

Что меняет мод:
- забег из 10 актов; враги с 4-го акта сильнее с ускорением, в 10-м втрое сильнее 3-го;
- мутации врагов с 4-го акта (1/2/3 по актам 4–6/7–9/10, боссы по одной): Прочный панцирь,
  Живучесть, Шипы, Изворотливость, Бешенство, Ритуал, Немезис, Артефакт, Отравитель (яд 2–8 за удар);
- Связка: половина урона по призывателю уходит его приспешникам;
- за мутированную элиту — зачарование карты на выбор;
- все персонажи и вся летопись открыты; золото x1,5;
- блок не сгорает в конце хода («Баррикада» и «Размытие» убраны, «Крепкий зажим» даёт 5 блока за ход);
- карты улучшаются сколько угодно раз, на 5-м улучшении — новое зачарование;
- на карте может быть несколько зачарований;
- магазин: удаление карт без ограничения, кнопка «Обновить» за золото;
- у костра «Слияние»: две одинаковые карты в одну, улучшения складываются +1, зачарования переносятся.

В совместной игре мод должен стоять у всех игроков.
