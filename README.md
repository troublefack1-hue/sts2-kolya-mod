# Мод Kolya Mod для Slay the Spire 2 (версия игры 0.107.1)

1. В Steam: правый клик по Slay the Spire 2 -> Управление -> Просмотреть локальные файлы.
2. Распакуйте этот архив в открывшуюся папку (рядом с SlayTheSpire2.exe должна появиться папка mods).
3. Запустите игру из Steam. В главном меню откройте «Моды» и согласитесь включить моды,
   затем перезапустите игру.

С модами игра ведёт отдельный профиль: обычные сохранения не затрагиваются.

Что меняет мод:
- забег из 10 актов, враги с 4-го акта плавно сильнее, в 10-м вдвое сильнее 3-го;
- все персонажи и вся летопись открыты;
- золото x1,5;
- блок не сгорает в конце хода («Баррикада» и «Размытие» убраны);
- карты можно улучшать сколько угодно раз;
- в магазине удалять карты без ограничения и кнопка «Обновить» за золото;
- у костра «Слияние»: две одинаковые карты становятся одной, улучшения складываются +1.

В совместной игре мод должен стоять у всех игроков.
