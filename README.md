# Мод Kolya Mod для Slay the Spire 2 (версия игры 0.107.1), версия мода 0.3.17

1. В Steam: правый клик по Slay the Spire 2 -> Управление -> Просмотреть локальные файлы.
2. Распакуйте этот архив в открывшуюся папку (рядом с SlayTheSpire2.exe должна появиться папка mods).
3. Запустите игру из Steam. В главном меню откройте «Моды» и согласитесь включить моды,
   затем перезапустите игру.

С модами игра ведёт отдельный профиль: обычные сохранения не затрагиваются.

## Изменено в 0.3.6 (11.11)

- исправлен чёрный экран при входе в комнату сокровищ на 4+ акте (игра умела только 3 акта);
- костёр на 4+ акте больше не падает с ошибкой «Unexpected act»;
- карты, у которых повторное улучшение больше ничего не меняло, получили рост статов: если
  ванильный апгрейд ничего не добавил, карта получает +2 к первому числовому стату (урон → блок →
  сила эффекта → исцеление); у карт совсем без чисел — дополнительное применение за уровень.

## Что меняет мод (все версии)

Что меняет мод:
- забег из 10 актов; враги с 4-го акта сильнее с ускорением, в 10-м втрое сильнее 3-го;
- мутации врагов с 1-го акта (1/2/3/4 мутации на актах 1–3/4–6/7–9/10, боссы с 4-го: 1/2/3):
  Прочный панцирь, Живучесть, Шипы, Изворотливость, Бешенство, Ритуал, Немезис, Артефакт,
  Отравитель (яд 1–8 за удар), Регенерация, Баррикада; сила мутаций растёт с актом;
  мутации делятся на 4 семейства (оборона/контроль/атака/заражение) — на одного врага
  не больше одной мутации из семейства, враг с 4 мутациями получает по одной из каждого;
  «Прочный панцирь» разрушаем: каждый ход, в котором по врагу нанесли больше урона, чем
  пропускает панцирь (20) — трещина, 3 трещины — панцирь снимается, враг получает Уязвимость 2;
- награда за мутированных врагов на 1–3 актах: фиксированное золото за каждого (10/15/20) каждому игроку;
- Связка: половина урона по призывателю уходит его приспешникам;
- за мутированную элиту — зачарование карты на выбор;
- все персонажи и вся летопись открыты; золото x1,5;
- блок не сгорает в конце хода («Баррикада» и «Размытие» убраны, «Крепкий зажим» даёт 5 блока за ход);
- карты улучшаются сколько угодно раз, на 5-м улучшении — новое зачарование; если повторный
  апгрейд ничего не меняет — +2 к первому числовому стату (или дополнительное применение);
  Таланты (карты Power) вместо этого сначала удешевляются на 1 за уровень до нулевой цены;
- на карте может быть несколько зачарований;
- магазин: удаление карт без ограничения, кнопка «Обновить» за золото (работает и в кооперативе);
- костёр: «Кузнец» улучшает карту сразу на 2 уровня;
- у костра «Слияние»: две одинаковые карты в одну, их уровни складываются и дают ещё +1 (две «+2» дают «+6» — уровень 7), зачарования объединяются.

В совместной игре мод должен стоять у всех игроков.
